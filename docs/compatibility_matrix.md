# Compatibility matrix

This is a compatibility record from the 2026-11-24 source audit and from what this machine can import. It is not a set of timing results. A row marked "not imported here" was not installed, so no CUDA smoke test exists for it.

| Component | Audited revision | What this project calls | This machine | Colab / server constraint |
| --- | --- | --- | --- | --- |
| PyTorch SDPA | torch 2.15.0 macOS wheel, CUDA build absent | `scaled_dot_product_attention`, backend named after a probe | Imports. CUDA is absent, so the baseline records `skipped_no_cuda`. | Keep the runtime's existing torch. The installer refuses to pip-install torch. BF16 only when compute capability is at least 8.0 and `is_bf16_supported()` is true. Otherwise the run is labeled FP16. A math SDPA kernel is labeled `pytorch_sdpa_math`, not FlashAttention. |
| FlashAttention package | `Dao-AILab/flash-attention` `b038b497` (2026-11-23), BSD-3-Clause | Not called by the single-GPU baseline. Ring and USP request it indirectly. | Does not import. | FA2 CUDA kernels are for sm_80 and newer. A T4 (sm_75) is outside that set. Current HEAD is FA4-era. ring-flash-attention 0.1.8 and yunchang 0.6.4 call FlashAttention 2 private functions. Do not assume HEAD installs beside them. |
| Ring Attention | `zhuzilin/ring-flash-attention` `78667793`, version 0.1.8, MIT. JAX reference `haoliuhl/ringattention` `d2ea1af9`, Apache-2.0. | `ring_flash_attn_func` and `zigzag_ring_flash_attn_func` | Package does not import. CPU schedule in `algorithms/ring_schedule.py` matches dense attention and is not the timed backend. | Needs CUDA, NCCL, and a compatible FlashAttention. Zigzag asserts causal attention. Dropout is unsupported. The audited backward casts `dq` to BF16. |
| DistFlashAttn | `RulinShao/LightSeq` `8f486dad` (2024-08-19) | `lightseq_async_attn.attention` after `initialize_distributed()` | Does not import. Code was not vendored. | No LICENSE file in the repository. The paper text is CC-BY-4.0. Odd GPU counts are rejected because the audited loop does not cover every causal block. Head dimension must be 16, 32, 64, or 128. Local sequence must be a multiple of `BLOCK_M` 128. Not a substitute for ring or zigzag. |
| DeepSpeed Ulysses | `deepspeedai/DeepSpeed` `140a2fbc` (2026-11-24), Apache-2.0 | `DistributedAttention(..., scatter_idx=2, gather_idx=1)` with `batch_dim_idx=0` | Does not import. | Heads must divide the Ulysses degree. The class default `gather_idx=0` is the wrong axis for BSHD. Open pull request 7868 reports shape bugs on other index paths. GPU numerical checks are still required before timing. |
| YunChang USP | `feifeibear/long-context-attention` `a5f8f600`, package yunchang 0.6.4, Apache-2.0 | `set_seq_parallel_pg` then `LongContextAttention(..., attn_type=AttnType.FA)` | Does not import. | Both degrees greater than 1 for genuine USP. `basic` plus `ring_low` is an invalid causal layout and is rejected. Zigzag at both placements matched the CPU reference. `AttnType.TORCH_EFFICIENT` has no backward and is not used for `forward_backward`. |

CPU schedule modules (`src/spbench/algorithms/`) emulate communication order with dense block attention so layouts and gradients can be checked without a GPU. Timed commands do not call them. A passing CPU test is not a CUDA result.
